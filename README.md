```

├── 02_Algorithms/         # 算法与数据结构
│   ├── Leetcode_Cplusplus/#  C++ 题解
```

## 学习路线

1. **编程基础** → 掌握 C++ / Python，能写能调
2. **算法** → LeetCode 刷题，理解常用数据结构
3. **AI 原理** → Transformer 源码实现 + BERT 微调
4. **LLM 应用** → Agent、LangChain、RAG 等范式
5. **视觉** → YOLO 检测、多目标追踪
6. **AI 应用开发** → 多模态 API、AI 产品原型
