# Blender 扫描模型：箱子中心对齐世界原点

## 方法一：自动法（物体 → 设置原点）

### 原理

Blender 自动对模型的**所有顶点**坐标取平均值，算出几何中心。

```
中心 = (所有顶点坐标之和) ÷ 顶点总数
```

### 操作步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 物体模式下选中箱子 | 大纲视图点击箱子名称，外框高亮 |
| 2 | 顶部菜单：**物体 → 设置原点 → 原点到几何中心** | 原点自动跳到模型中心，可能肉眼看不到变化 |
| 3 | 按 `N` → 变换面板 → **位置 X/Y/Z** 全部改为 `0` | 箱子移到世界原点 |
| 4 | 按小键盘 `.` 或 `~` → 查看所选 | 验证视角 |

### 优点

- 操作简单，两步完成
- 无需进入编辑模式
- 适用于任何模型

### 缺点

- 扫描模型表面顶点密度不均 → **中心会偏向顶点密的一侧**
- 表面有噪点、残留 → **噪点会参与计算，中心不准**
- 无法亲眼确认计算结果

### 适用场景

- 表面顶点分布均匀的模型
- 快速预览，不要求精度
- 标准的几何体模型（方块、球体等）

## 方法二：8 点法（手动选角顶点）

### 原理

手动挑选箱子的 **8 个物理角顶点**，仅用这 8 个点计算中心，**忽略所有其他顶点**。

```
中心 = (8个角的坐标之和) ÷ 8
```

### 操作步骤

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 选中箱子，按 `Tab` 进入编辑模式 | 显示网格线框，顶点为蓝色小点 |
| 2 | 按 `1` 切换到顶点选择模式 | 左上角顶点图标亮起 |
| 3 | 按 `Alt + A` 取消全选 | 所有顶点恢复蓝色，无橙色高亮 |
| 4 | **按住 Shift**，左键逐个点选 8 个角 | 每点一个变橙色，共 8 个角高亮 |
| 5 | 按 `Shift + S` → **游标到选中项** | 游标跳到 8 个角的几何中心 |
| 6 | 按 `Tab` 回到物体模式 | 恢复实体显示，游标停留在中心 |
| 7 | 菜单：**物体 → 设置原点 → 原点到 3D 游标** | 原点跳到游标位置 |
| 8 | 按 `N` → 变换面板 → **位置 X/Y/Z** 全部改为 `0` | 箱子中心对齐世界原点 |
| 9 | 按小键盘 `.` 或 `~` → 查看所选 | 确认坐标原点在箱子正中心 |

### 优点

- **不受扫描噪点和顶点密度影响**，比自动法更精确
- 第 5 步能亲眼看到游标落在中心，心中有数

### 缺点

- 操作步骤多，需手动选点
- 要求箱子的角部位清晰可见，没有大面积缺失

### 适用场景

- 3D 扫描、点云重建的模型
- 需要精确对齐、装配、测量的场合
- 模型表面有凹凸、噪点、密度不均时

## 补充：N 键（变换面板）说明

按 `N` 键弹出的侧边栏是 **变换面板**，常用属性如下：

| 属性 | 含义 | 示例 |
|------|------|------|
| **位置 X / Y / Z** | 物体原点在世界空间中的坐标 | `0, 0, 0` = 世界原点 |
| **旋转 X / Y / Z** | 物体绕各轴的旋转角度 | `0°, 0°, 0°` = 无旋转 |
| **缩放 X / Y / Z** | 物体在各轴向上的缩放倍数 | `1.0, 1.0, 1.0` = 原始尺寸 |
| **尺寸 X / Y / Z** | 物体包围盒的实际物理尺寸 | 如 `0.5m, 0.3m, 0.4m` |

> 💡 **位置归零**就是把位置 X/Y/Z 都设为 0，物体中心即对齐世界原点。
