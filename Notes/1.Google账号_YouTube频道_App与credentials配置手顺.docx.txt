Google账号、YouTube频道、Google Cloud App与credentials.json配置手顺
范围：创建/准备Google账号 → 开通YouTube频道 → 创建Google Cloud项目与OAuth App → 下载credentials.json → 统一账号管理原则
核心原则：先确定一个项目专用 Google 邮箱。YouTube、Google Cloud、credentials.json、Meta账号、IG账号、Meta Developer App 后续都围绕这个邮箱管理。
0. 总原则：所有平台账号统一用同一个Google邮箱管理
* 为了后续 YouTube、Meta、Instagram、Google Cloud、OAuth token、credentials.json、运营后台权限都容易管理，建议先确定一个专用运营邮箱。
* 之后的 Meta 账号、IG 账号、Facebook Page、Instagram Professional Account、Meta Developer App，也都尽量使用这个 Google 邮箱注册或绑定。
* 不要使用个人生活邮箱。建议使用一个长期可控、可找回、开启二步验证的项目专用 Gmail。
1. 创建或准备Google账号
* 打开 Google 账号创建页面，创建一个新的 Gmail / Google Account。
* 建议邮箱命名与项目或频道矩阵相关，例如 projectname.media@gmail.com、projectname.ops@gmail.com。
* 创建后立即完成手机号验证、备用邮箱、二步验证。
* 把账号信息记录到安全的密码管理器中，不要写进代码仓库、Notion公开页或共享表格。
* 以后登录 YouTube、Google Cloud Console、OAuth 授权时，都使用这个账号。
2. 使用该Google账号登录YouTube并开通频道
* 用上一步创建的 Google 账号登录 YouTube。
* 点击右上角头像，进入“创建频道”或“Your channel / Create channel”。
* 填写频道名称、Handle、头像。频道名可以先用项目品牌名，Handle 尽量保持和 IG / TikTok / X 等平台一致。
* 创建完成后，进入 YouTube Studio，确认频道可以正常进入后台。
* 如果是长期运营矩阵，建议优先使用 Brand Account / 品牌账号结构，方便后续添加管理员。
3. 创建Google Cloud项目
* 打开 Google Cloud Console，并确认右上角登录的是同一个 Google 邮箱。
* 进入项目选择器，点击“New Project / 新建项目”。
* 项目名称建议使用：youtube-upload-prod、content-ops-youtube、或频道/项目名。
* 创建项目后，确认页面顶部当前选中的项目就是刚创建的项目。
4. 启用YouTube Data API v3
* 在 Google Cloud Console 左侧菜单进入 APIs & Services → Library。
* 搜索 YouTube Data API v3。
* 进入该 API 页面后点击 Enable / 启用。
* 启用后回到 APIs & Services → Enabled APIs，确认 YouTube Data API v3 已在列表中。
5. 配置OAuth consent screen / OAuth同意屏幕
* 进入 APIs & Services → OAuth consent screen。
* 如果只给自己或内部测试账号使用，可以选择 External，然后保持 Testing 状态；如果未来给大量外部用户使用，需要走 Google 验证。
* 填写 App name。建议与项目名一致，例如 YouTube Upload Operator。
* User support email 和 Developer contact information 都填写这个项目专用 Google 邮箱。
* Scopes 阶段可以先保存，后面按脚本需要添加。自动上传视频通常需要 https://www.googleapis.com/auth/youtube.upload。
* 在 Test users 中添加这个 Google 邮箱。否则 Testing 状态下 OAuth 登录可能无法通过。
6. 创建OAuth Client，并下载credentials.json
* 进入 APIs & Services → Credentials。
* 点击 Create Credentials → OAuth client ID。
* Application type 根据你的脚本运行方式选择。若是本地 Python / Docker 脚本，一般选择 Desktop app。若是网页后台回调模式，选择 Web application，并配置 Authorized redirect URIs。
* Name 可以写 youtube-upload-local-client 或 youtube-upload-web-client。
* 点击 Create 后，会显示 Client ID 和 Client Secret。
* 点击 Download JSON，下载得到的 JSON 文件就是 credentials.json。
* 把下载文件改名为 credentials.json，放到你的项目指定位置，例如项目根目录或 config/secrets 目录。
* 注意：credentials.json 不能提交到 GitHub。需要加入 .gitignore。
7. OAuth授权并生成本地token文件
* credentials.json 只是 OAuth App 的客户端配置，不等于用户授权。
* 第一次运行上传脚本时，脚本会用 credentials.json 打开浏览器，让你选择 Google 账号。
* 这一步必须选择前面创建并已开通 YouTube 频道的同一个 Google 邮箱。
* 授权成功后，脚本通常会在本地生成 token 文件，例如 token.pickle、token_personal.pickle 或 token.json。
* 后续自动上传真正依赖的是 token 文件里的 access token / refresh token。credentials.json 用于启动 OAuth 流程，token 文件用于代表该 YouTube 频道执行上传。
8. 项目中建议保存的文件和环境变量
* 建议文件结构：credentials.json 放在本地安全目录；token 文件按 profile 保存；.env 中只写路径，不直接写密钥内容。
* 例如：GOOGLE_CREDENTIALS_PATH=/app/credentials.json，GOOGLE_TOKEN_PATH=/app/token_personal.pickle。
* 如果以后做多频道，每个频道应该有独立 profile 和独立 token 文件，避免授权错账号。
9. 与Meta / IG账号的统一管理要求
* 从这个步骤之后，所有和该内容矩阵相关的新账号，都尽量使用同一个 Google 邮箱注册或绑定。
* Meta账号：使用该 Google 邮箱作为登录邮箱。
* Facebook Page：用该 Meta 账号创建或管理。
* Instagram账号：使用该 Google 邮箱注册，或至少绑定该邮箱作为联系邮箱。
* Instagram Professional Account：用这个 IG 账号切换 Business / Creator。
* Meta Developer App：用同一个 Meta 账号创建，便于和 Facebook Page、IG Professional Account、OAuth权限统一管理。
* 这样做的好处是：权限归属清晰、账号恢复方便、OAuth授权时不容易选错账号、后续交接和多账号矩阵管理更简单。
10. 最小完成检查表
* 已经有一个项目专用 Google 邮箱。
* 该 Google 邮箱已开启二步验证，并设置备用邮箱/手机号。
* 用该 Google 邮箱创建了 YouTube 频道。
* 可以进入 YouTube Studio。
* Google Cloud 中已创建项目。
* 该项目已启用 YouTube Data API v3。
* OAuth consent screen 已完成基础配置。
* Test users 中已添加该 Google 邮箱。
* Credentials 中已创建 OAuth client ID。
* 已下载 credentials.json。
* credentials.json 已放入项目安全目录，并已加入 .gitignore。
* 后续 Meta / IG / Facebook Page / Meta Developer App 都使用或绑定这个 Google 邮箱。
11. 参考来源
* Google / YouTube Help: You need a Google Account to sign in to YouTube, and after signing in you can create a YouTube channel.
* YouTube Help: Create a YouTube channel, including choosing a profile picture, name, and Handle.
* YouTube Data API documentation: The API uses OAuth 2.0 authorization credentials and you create credentials from the Google API Console.
